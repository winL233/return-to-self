# 归自己 Return to Self

分手后，帮一个人把**被关系搁浅的、本来就会的自己**重新激活。

不是疗愈聊天，不是断联计时器，是一个轻盈的**每日记录与行为工具**。

## 三个核心动作

| 功能 | 一句话 | 对应那件事 |
|---|---|---|
| 想念记录 | 想/不想 → 程度低/中/高，一次进来只记一条 | 把看不见的抽身进度，变成看得见的曲线 |
| 我的事 | 添加只属于自己的事 → 做 → 完成 + 评价 | 让"独自运转的自己"重新跑起来 |
| 进度 | 想念走势（日/周/月）+ 做过的事 | 看到自己在回来 |

约束：同一件事同时只有一条进行中；全局最多并行 3 件；做和完成都能撤回。只有「做完 + 评价」才算一条有效证据。

## 数据存在哪

**全部存在你自己的浏览器里（localStorage），不上传任何服务器。**

- 换设备 / 清缓存会丢 → 用 App 内「导出全部备份（JSON）」保存，再到新设备「导入备份」
- 想把数据贴进表格做分析 → 用「导出 CSV」

## 本地打开

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

## 关于隐私

代码里没有任何密钥、没有任何个人数据。仓库是公开的，但打开链接的人看到的只会是一个全新的空白 App——你的记录永远只在你自己的设备上。
